## 🎯 Learning Approach

For each topic, I try to follow this process:

```text
Concept
   ↓
Understand the mathematics
   ↓
Study the Scikit-learn implementation
   ↓
Write the code myself
   ↓
Experiment with data
   ↓
Evaluate the model
   ↓
Document what I learned
```

The goal is not just to learn how to call a machine learning library, but to understand **what the algorithms are doing and why they work**.
